About

I'm a full-stack developer based in Portland, working mostly in React, Node, and Python. I like projects with a real constraint — a deadline, a dataset, a stubborn user — because that's where the interesting decisions live.


Before freelancing I spent three years on a small team building internal tools for a logistics company, which is where I learned that the best interface is the one nobody has to think about. Outside of work I restore old synthesizers and run a very slow book club.
